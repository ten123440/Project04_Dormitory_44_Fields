# วิธีใช้ข้อมูลเพิ่มเติม

สมาชิกกรอกข้อมูลนักศึกษาใน /register และเพิ่มวันสิ้นสุดที่คาดไว้/หมายเหตุในฟอร์ม /rooms ได้ การจองเก่าที่ไม่มีราคาตอนจองจะแสดงว่าไม่ระบุ

ผู้ดูแลเพิ่มอาคารจากส่วนข้อมูลอาคารใน /admin/dashboard แล้วเลือกอาคารเมื่อเพิ่มห้องใหม่ ห้องเดิมที่ยังไม่ผูกอาคารยังใช้งานได้ หากต้องการผูกห้องเดิม ใช้ PUT /api/rooms/{id} พร้อม building_id ผ่าน token ผู้ดูแล หรือแก้ค่า FK ที่ตรวจสอบแล้วในฐานข้อมูล

ประเภทห้องใน /admin/room-types มีรายละเอียด ความจุ และเงินประกัน สัญญาใหม่จะบันทึกค่าเช่าและเงินประกันจากประเภทห้องโดยอัตโนมัติ

ฟิลด์ใหม่เป็น optional สำหรับ client เดิม Flutter models รองรับข้อมูลใหม่ แต่แบบฟอร์มกรอกข้อมูลใหม่อยู่ในหน้าเว็บ Blade
