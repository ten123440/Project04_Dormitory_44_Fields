ชุดนี้เป็นการขยายฐานข้อมูลและเชื่อมฟิลด์เข้ากับส่วนงานเดิม ไม่ใช่การรับรองความสมบูรณ์หรือความปลอดภัยทั้งระบบเดิม Laravel 12 และระบบ token เดิมต้องตรวจเพิ่มเติมก่อนใช้งานจริง

## ขั้นตอนตรวจรับบนเครื่องจริง

1. สำรองฐานข้อมูลเดิม แล้วรัน php artisan migrate ใน backend
2. รัน database/verify_44_fields.sql ในฐานข้อมูลเดียวกัน ต้องได้ users=10, room_types=7, rooms=8, bookings=11, buildings=8
3. ตรวจจำนวนแถวในตารางเดิมว่าเท่าเดิมหลัง migrate และไม่มีการ seed เพิ่ม
4. สมัครสมาชิกพร้อม student_code แล้วลองสมัครรหัสซ้ำ ต้องถูกปฏิเสธ; ไม่ระบุรหัสยังสมัครได้
5. เข้าผู้ดูแล เพิ่มอาคาร/ประเภทห้อง/ห้องใหม่ และตรวจ FK ของ building_id
6. จองห้องโดยให้ check_out_date ก่อน check_in_date ต้องถูกปฏิเสธ จากนั้นกรอกวันที่ถูกต้องและ notes
7. ตรวจ bookings ว่า monthly_rate และ deposit_amount ตรงกับประเภทห้อง ณ วันจอง รวมทั้ง created_at ถูกสร้าง
8. แก้ราคาประเภทห้องในฐานข้อมูลทดสอบแล้วตรวจสัญญาที่สร้างไว้ ต้องคงราคาที่บันทึกเดิม
9. เปิด start.bat ครั้งต่อไป ตรวจว่าข้อมูลยังอยู่

หากอัปเกรดผ่าน migration ให้ rollback เฉพาะเมื่อยอมรับว่าคอลัมน์ใหม่และข้อมูลอาคารจะถูกลบ; ใช้ backup หากต้องกู้คืนข้อมูลทั้งหมด

## แพตช์ Composer

ตรวจ JSON แล้ว laravel/framework ใช้ ^12.0, php ใช้ ^8.2 และ PHPUnit ^11.0 ตามคู่มือ Laravel 12 ตรวจโค้ดแล้วไม่พบ HasUuids, diffIn*, image validation หรือ Concurrency ที่ต้องปรับตามหัวข้อ breaking changes ของคู่มือ ยังคงต้องทดสอบ Composer resolution และ smoke test บน PHP/MySQL จริง
