# ข้อกำหนดการปรับ Project 04

แหล่งที่มา: ผู้ใช้ขอเพิ่มฐานข้อมูล Project 04 ให้มี 44 ฟิลด์ และอนุญาตเพิ่มตาราง

| รายการ | การดำเนินการ | สถานะ |
|---|---|---|
| ตรวจโปรเจกต์ 04 เดิม | อ่าน migrations/models/controllers/views | เดิมระบบหอพัก 24 ฟิลด์ |
| รวม 44 ฟิลด์ | เพิ่ม buildings 8 ฟิลด์ และ 12 ฟิลด์ใน 4 ตารางเดิม | ทำแล้ว |
| รองรับโค้ดเดิม | optional validation, fillable, relation และฟอร์ม Blade | ตรวจ static |

การเลือกเพิ่มข้อมูลอาคาร นักศึกษา และสัญญาเช่าเป็นทางเลือกออกแบบตามระบบเดิมเพื่อให้ฟิลด์มีความหมาย ไม่ได้เพิ่มระบบจ่ายเงินหรือแจ้งซ่อม
ไฟล์ SQL ใหม่และ migration ใหม่ตรงกัน โดยคงข้อมูลเดิมไว้ในการอัปเกรด
